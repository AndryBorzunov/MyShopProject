# Объектно Ориентированное Программирование

## Класс Product

- Добавлен геттер и сеттер price - цена продукта
- Функция создания экземпляра класса Product из данных о продукте в словаре
- Добавлено переопределение строкового представления класса
- Сложение общей суммы стоимости продуктов при сложении экземпляров класса
- При сложении объектов проверяется, что объекты относятся к одинаковому типу
- Если пользователь создает товар (метод __init__) с нулевым количеством, вызывается
        исключение ValueError, которое выдает сообщение:
        "Товар с нулевым количеством не может быть добавлен".
        При этом прерывается выполнение программы.


## Класс Category

- Категории продуктов
- функция добавления продукта в категорию
- Вывод списка продуктов в виде форматированной строки
- Переопределение строкового представления класса -
        выводит имя категории и общее количество продуктов
- При добавлении продукта в категорию выполняется проверка - 
        является ли добавляемый объект продуктом
- Реализован метод __middle_price__, который подсчитывает средний ценник всех товаров.
        С помощью исключений обработан случай, когда в категории нет товаров
        и сумма всех товаров делится на ноль. Если такое происходит, возвращается ноль.


## Класс Iterator

- Реализует итерацию товаров по категориям


## Классы Smartphone и LawnGrass

- Являются наследниками класса Product
- Содержат дополнительные аттрибуты


## Абстрактный класс BaseProduct

- Предназначен для создания классов продуктов
- Содержит в себе общие свойства и методы


## Класс-миксин MixinLog

- При создании объекта, то есть при работе метода __init__,
печатает в консоль информацию о том, от какого класса и с какими параметрами был создан объект.
